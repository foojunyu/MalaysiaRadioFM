# Malaysia Radio FM - User Guide

## Getting Started

Welcome to Malaysia Radio FM, your desktop application for streaming popular Malaysian radio stations!

### First Time Setup

1. **Installation**
   - Download the latest release from the GitHub releases page
   - Extract the ZIP file to a folder of your choice
   - Double-click `MalaysiaRadioFM.exe` to launch the application

2. **System Requirements**
   - Windows 10 or later
   - .NET 8.0 Desktop Runtime (will prompt to download if not installed)
   - Active internet connection for streaming

## Using the Application

### Main Interface

The application consists of four main sections:

1. **Header** - Shows the application title and description
2. **Station List** - Displays all available radio stations
3. **Control Panel** - Play/Stop buttons and volume control
4. **Status Bar** - Shows current playback status

### Playing a Radio Station

1. Select a station from the list by clicking on it
2. Click the **▶ Play** button
3. Wait a few seconds for the stream to connect
4. The status bar will show "Playing" when the stream starts

### Controlling Playback

- **Play Button** (▶ Play) - Start streaming the selected station
- **Stop Button** (⏹ Stop) - Stop the current stream
- **Volume Slider** - Adjust volume from 0% to 100%
  - Drag the slider left to decrease volume
  - Drag the slider right to increase volume
  - The current volume percentage is displayed next to the slider

### Switching Stations

To switch to a different station:
1. Click the **⏹ Stop** button to stop the current stream
2. Select a new station from the list
3. Click **▶ Play** to start the new stream

Or simply:
1. Select a new station from the list
2. Click **▶ Play** (this will automatically stop the previous stream)

## Troubleshooting

### Common Issues

**Problem: No sound when playing**
- Check your computer's volume settings
- Ensure your speakers/headphones are connected
- Try adjusting the volume slider in the application
- Check your internet connection

**Problem: "Error" message appears**
- The radio station stream may be temporarily unavailable
- Try selecting a different station
- Check your internet connection
- Restart the application

**Problem: Connection takes too long**
- This is normal for the first connection to a station
- Wait 5-10 seconds for the stream to buffer
- If it takes longer than 30 seconds, try stopping and playing again

**Problem: Application won't start**
- Ensure .NET 8.0 Desktop Runtime is installed
- Right-click the executable and select "Run as administrator"
- Check Windows Event Viewer for error details

### Getting Help

If you encounter issues not covered here:
1. Check the README.md file for technical information
2. Visit the GitHub repository for updates and issue tracking
3. Submit an issue on GitHub with:
   - Description of the problem
   - Steps to reproduce
   - Error messages (if any)
   - Your Windows version

## Tips and Best Practices

1. **Internet Connection**: Ensure you have a stable internet connection for uninterrupted streaming
2. **Volume Levels**: Start with 50% volume and adjust based on your preference
3. **Multiple Stations**: Feel free to explore different stations to find your favorite
4. **Minimize Distractions**: The application can run in the background while you work
5. **Save Battery**: If on a laptop, be aware that streaming uses data and battery

## Technical Notes

- The application uses approximately 128-256 kbps of bandwidth per stream
- Audio is streamed in real-time; there's no recording or storage of content
- Station availability depends on the broadcaster's stream status
- Some streams may have geographic restrictions

## Privacy

- This application does not collect any personal data
- No telemetry or analytics are sent
- Stream URLs are accessed directly without tracking
- No cookies or local storage are used

## Keyboard Shortcuts

Currently, the application does not support keyboard shortcuts. All controls are accessible via mouse/touch input.
